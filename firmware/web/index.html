Google accounts

How to get the URL and token
  1. Sign in to the Google account at script.google.com and create a project.
  2. Paste Code.gs and appsscript.json from the repository's apps-script folder and set your own TOKEN.
  3. Run preview once to allow access, then Deploy › New deployment › Web app (Execute as: Me, Access: Anyone).
  4. Paste the web app URL and the token here.

Outlook, iCloud & other (ICS)

This firmware can't show ICS calendars yet. Update it on the Device tab.

Where to find the link
  1. Outlook: Settings › Calendar › Shared calendars › Publish a calendar, then copy the ICS link.
  2. iCloud: in the Calendar app, share the calendar as a Public Calendar and copy the link.
  3. Other: any link ending in .ics or starting with webcal://.

Smart desk

Without a login only the memory buttons and Stop work. Raise, lower, the sit/stand timer and away mode need a desk account with the user role.
